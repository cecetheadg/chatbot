🇬🇳 Chatbot L0027 - Guide d'intégration

Intégrez l'assistant de la Fonction Publique guinéenne à votre site web

Méthodes d'intégration

Choisissez la méthode qui convient le mieux à votre projet :

Intégration par Iframe

La méthode la plus simple. Intégrez le widget dans une iframe.

<!-- Intégration iframe simple --> <iframe src="https://votre-api.com/static/widget.html?api=https://votre-api.com/api/v1" width="400" height="600" frameborder="0" style="border-radius: 16px; box-shadow: 0 10px 40px rgba(0,0,0,0.1);" ></iframe>

✅ Avantages

Installation en 1 ligne, isolation complète, aucune dépendance

⚠️ Limitations

Personnalisation limitée, taille fixe

Script d'intégration (Bouton flottant)

Ajoutez un bouton de chat flottant à votre site avec un simple script.

<!-- Ajoutez ce script avant </body> --> <script src="https://votre-api.com/static/embed.js" data-api-url="https://votre-api.com/api/v1" data-position="bottom-right" data-theme="blue" ></script>

Options de configuration :

Attribut Description Valeurs
data-api-url URL de l'API du chatbot URL complète
data-position Position du bouton bottom-right, bottom-left
data-theme Thème de couleur blue, green, dark
data-width Largeur de la fenêtre Ex: 400px
data-height Hauteur de la fenêtre Ex: 600px

API JavaScript :

// Ouvrir le chatbot ChatbotL0027.open(); // Fermer le chatbot ChatbotL0027.close(); // Basculer l'état ChatbotL0027.toggle(); // Poser une question programmée ChatbotL0027.askQuestion("Quel est l'âge de la retraite ?"); // Vérifier si ouvert if (ChatbotL0027.isOpen()) { console.log('Le chatbot est ouvert'); }

Composant React

Pour les applications React/Next.js.

// Installation npm install @votre-org/chatbot-l0027 // Ou copiez ChatbotL0027.jsx dans votre projet

Usage basique :

import { ChatbotL0027 } from './ChatbotL0027'; function App() { return ( <div> <h1>Mon Application</h1> {/* Bouton flottant avec chatbot */} <ChatbotL0027 apiUrl="https://votre-api.com/api/v1" position="bottom-right" /> </div> ); }

Widget intégré (sans bouton flottant) :

import { ChatbotWidget } from './ChatbotL0027'; function SupportPage() { return ( <div className="support-container"> <h1>Centre d'aide</h1> {/* Widget intégré dans la page */} <ChatbotWidget apiUrl="https://votre-api.com/api/v1" embedded style={{ height: '500px' }} /> </div> ); }

Avec Hook personnalisé :

import { ChatbotProvider, useChatbot, ChatbotWidget } from './ChatbotL0027'; function CustomButton() { const { toggle, isOpen } = useChatbot(); return ( <button onClick={toggle}> {isOpen ? 'Fermer' : 'Aide'} </button> ); } function App() { return ( <ChatbotProvider apiUrl="..."> <CustomButton /> {/* Votre contenu */} </ChatbotProvider> ); }

Appels API directs

Pour une intégration personnalisée complète.

Endpoint principal :

POST /api/v1/ask Content-Type: application/json { "question": "Quel est l'âge de la retraite ?", "session_id": "optional-session-id", "llm_provider": "openai", "include_suggestions": true }

Exemple JavaScript :

async function askChatbot(question) { const response = await fetch('https://votre-api.com/api/v1/ask', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ question: question, include_suggestions: true }) }); const data = await response.json(); console.log('Réponse:', data.answer); console.log('Articles:', data.articles_references); console.log('Suggestions:', data.suggested_questions); return data; }

Endpoints disponibles :

Méthode Endpoint Description
POST /api/v1/ask Poser une question
GET /api/v1/search/articles Rechercher des articles
GET /api/v1/articles/{numero} Obtenir un article
GET /api/v1/suggestions/popular Questions populaires
GET /api/v1/suggestions/starter Questions de démarrage
GET /api/v1/categories Liste des catégories
GET /health État du système

Démonstration

Testez le chatbot en direct :

Configuration requise

🔧 Backend

API FastAPI déployée et accessible (CORS configuré)

🔑 Clés API

Au moins une clé LLM (OpenAI recommandé)

📦 Services

PostgreSQL, Redis, Qdrant

🌐 HTTPS

Recommandé en production

Configuration CORS

Assurez-vous que votre domaine est autorisé dans la configuration FastAPI :

# app/main.py app.add_middleware( CORSMiddleware, allow_origins=[ "https://votre-site.com", "https://www.votre-site.com", ], allow_credentials=True, allow_methods=["*"], allow_headers=["*"], )
